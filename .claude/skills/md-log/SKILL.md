# md-log

The terminal doesn't render LaTeX or Mermaid; Obsidian does. This mirrors the session into a note in `~/Documents/AI Engineering/`. The note is regenerated by a hook after every quiz / question and at the end of every turn, always containing the whole session so far — so linking mid-session backfills everything before it.

Arguments: `$ARGUMENTS`

- **empty** → `python3 .claude/tools/md_log.py link` (creates `Sessões/<data> <hora>.md`).
- **`off`** → `python3 .claude/tools/md_log.py off`.
- **`status`** → `python3 .claude/tools/md_log.py status`.
- **anything else** → it's the note: `python3 .claude/tools/md_log.py link "<nota>"`. A relative path is relative to the vault; a bare name goes in `Sessões/` (prefix it with `Sessões/`). `.md` is added if missing.

Tell the user where the log goes, in one line. Nothing else is needed: the hook writes the note when this turn ends.

This is the **raw** record. The consolidated content (lesson notes, concepts) is written by `teach` Phase 4, not here.
